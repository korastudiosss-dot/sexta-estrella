SEXTA ESTRELLAPolítica de privacidad

Última actualización: 17/11/2026 · Responsable: Sexta Estrella · Contacto: korastudiosss@gmail.com

1. A quién afecta

Esta política describe qué datos trata la herramienta de escritorio de Sexta Estrella («la aplicación»). La aplicación solo se conecta a las cuentas propias del canal. No ofrece registro a terceros, no tiene usuarios externos y no recoge datos de quienes ven nuestros vídeos.

2. Datos que trata la aplicación

  • Tokens de acceso de TikTok, YouTube (Google) e Instagram (Meta) de las cuentas del canal, obtenidos con el consentimiento expreso del titular mediante OAuth.
  • Datos básicos de esas cuentas que devuelven las API: identificador, nombre visible y nombre de usuario.
  • Datos de nuestras publicaciones: identificadores, estado de publicación y métricas agregadas (visualizaciones, me gusta, comentarios, compartidos, retención).

No tratamos datos de otros usuarios de las plataformas, no leemos mensajes privados y no descargamos listas de seguidores.

3. Para qué

Exclusivamente para publicar los vídeos del canal, confirmar que se han publicado y medir su rendimiento.

4. Dónde se guardan

En el ordenador del responsable, en archivos locales no compartidos. Los tokens nunca se publican ni se envían a terceros. Los vídeos y sus textos se envían únicamente a la plataforma correspondiente a través de su API oficial.

5. Terceros

Usamos ElevenLabs para generar la narración a partir de guiones propios; no se le envían datos personales. TikTok, Google y Meta tratan los datos según sus propias políticas. La aplicación usa los servicios de la API de YouTube; consulta la Política de privacidad de Google.

6. Conservación y retirada

Los tokens se conservan mientras la conexión esté activa y se borran al desconectar la cuenta. Puedes revocar el acceso en cualquier momento desde la configuración de seguridad de Google, TikTok o Meta. Para cualquier consulta o solicitud de borrado, escribe a la dirección de contacto.

Puedes ejercer tus derechos de acceso, rectificación, supresión, oposición, limitación y portabilidad escribiendo a la dirección de contacto, y presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es).

7. No vendemos datos

No vendemos, alquilamos ni cedemos datos a nadie.

English summary

The Sexta Estrella desktop tool connects only to the channel's own TikTok, YouTube and Instagram accounts. It stores their OAuth tokens and basic account fields locally on the owner's computer, uses them only to publish the channel's videos, confirm publication and read aggregate metrics, and never shares or sells them. It collects no data about viewers or other users. The tool uses YouTube API Services; see the Google Privacy Policy. Access can be revoked at any time from each platform's security settings. Contact the address above for any request.
